WEBCRAFT 3D

웹 브라우저에서 즐기는 3D 마인크래프트 세계에 오신 것을 환영합니다!

🎮 조작법:
• WASD / 화살표 : 이동
• 마우스 이동 : 시점 회전 (화면 클릭)
• 좌클릭 : 블록 파괴
• 우클릭 : 블록 설치
• 스페이스바 : 점프 / 비행 시 상승
• Shift : 크라우치(숙이기) / 비행 시 하강
• 1 ~ 9 키 : 핫바 슬롯 선택
• E 키 : 인벤토리 창 열기
• F 키 : 비행 모드 토글

보관함 (인벤토리)

원하는 블록을 클릭하여 현재 선택된 핫바 슬롯에 배치하세요.
